# Exercise 3: Finish implementation of entries

The application currently has functionality to add and view entries - this exercise implements the remaining operations.
For each of the following requirements perform the following steps:
1. Determine any acceptance criteria
2. Write a scenario for each acceptance criteria and implement as a functional acceptance test
3. Implement the functionality to make the test pass
4. Commit and push the changes back to your repository in GitHub and confirm that the workflows all pass


## Requirement: Updating an entry

We need the ability to update a previously created entry - use the tests/implementation for updating a register
as a reference.



## Requirement: Deleting an entry

We need the ability to delete a previously created entry - use the tests/implementation for deleting a register
as a reference.


## Requirement: Only empty registers can be deleted

If a register has entries, then the application should not allow it to be deleted.
